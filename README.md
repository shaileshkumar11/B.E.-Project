**Voice Operated Lift** is our Final Year BE project that uses **voice commands** to control lift operations.  
The system is designed for improved accessibility and automation in buildings, enabling hands-free operation for users, including those with mobility challenges.

---

## Overview

This project allows lift operation via **speech recognition**, enabling users to:
- Call the lift to a specific floor
- Open/close doors
- Move between floors without pressing buttons

The system integrates **voice modules**, **microcontrollers**, and **motor drivers** to provide reliable and safe lift control.

---

## Features

- **Hands-free Control:** Operates using simple voice commands.
- **User Accessibility:** Helpful for physically challenged and elderly people.
- **Multi-floor Support:** Handles commands for multiple floors.
- **Safety Integration:** Stops lift if an obstruction is detected.
- **Customizable Commands:** Voice module can be trained for specific phrases.

---

## Tech & Infrastructure

### **Hardware**
- **Microcontroller:** Arduino / Microcontroller Board
- **Voice Recognition Module**
- **Motor Driver Circuit**
- **Lift Motor (DC/AC)**
- **Safety Sensors** (for obstruction detection)
- **Power Supply Unit**

### **Software**
- **Language:** Embedded C / Arduino C
- **IDE:** Arduino IDE
- **Control Logic:** Voice input → Microcontroller processing → Motor control signals

---

## System Flow

1. **Voice Command Input** — User speaks a predefined command.
2. **Voice Recognition Processing** — Voice module identifies the command.
3. **Microcontroller Control** — Command is mapped to a lift function.
4. **Motor Driver Activation** — Moves lift or opens/closes doors.
5. **Safety Checks** — Obstruction sensors ensure safe operation.
